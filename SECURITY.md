# Security Policy

Identica decides who may join a network as which account, so a flaw in it can let a player into someone else's account or past authentication entirely.

## Supported versions

Security fixes go into the next release built from `dev`. Only the latest release receives them; update to it before reporting.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/whereareiam/Identica/security/advisories/new). Do not open a public issue, pull request, or Discord message with the details.

Include:

- the Identica version, proxy, providers, and database or replication setup
- what an attacker can do, and what they need for it
- steps to reproduce

You receive an answer on the report. The fix is released before the details are published, and the release notes name it as a security fix.
